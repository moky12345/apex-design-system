## 🎯 Strategic Purpose

When scaling multi-brand e-commerce portfolios, maintaining visual cohesion while rapidly prototyping high-converting landing pages requires a robust design system. 

**Apex UI** establishes standardized design tokens, modular UI components, and accessible interaction patterns that bridge the gap between **Figma wireframes** and **production Shopify / front-end implementations**.

---

## 🧩 Component Architecture

| Category | Components Included |
| :--- | :--- |
| **Foundations** | Semantic Color Tokens (Brand, Accent, Feedback, Neutrals), Responsive Typography scale, Elevation tokens. |
| **Action Triggers** | Primary Add-to-Cart buttons, Secondary promotional buttons, Outline / Ghost buttons, Disabled and Active states. |
| **Conversion Badges** | Verified Buyer tags, Limited Stock scarcity alerts, Promotional discount pills (`Save 20%`), and Sold Out chips. |
| **Interactive Controls** | Accessible Quantity Stepper (`−` / `+`), 5-Star Rating Picker, and Animated Toast Alerts. |

## 🚀 How to Run

1. Clone or download this repository:
   ```bash
   git clone https://github.com/moky12345/apex-design-system.git
   cd apex-design-system
   ```
2. Open `index.html` in any web browser.
3. Click any color token or code snippet to copy values directly to your clipboard, and test the interactive rating and stepper components.

---

## 🛠️ Technology Stack
- **HTML5 & Modern CSS3**: CSS Custom Properties (Variables), semantic markup, accessible focus indicators.
- **Vanilla JavaScript (ES6+)**: Zero-dependency interaction logic, clipboard API integration, dynamic SVG star rating calculation.
